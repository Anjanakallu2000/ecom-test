# Circular Fashion — Premium Ecommerce Frontend

Static HTML/CSS/JS demo with:
- Separate pagination pages: shop.html, shop-page-2.html, shop-page-3.html, shop-page-4.html
- Product categories and collections
- Product detail pages with variants, wishlist and cart
- Search modal
- Cart stored in localStorage
- Wishlist stored in localStorage
- Account/dashboard demo pages
- Circularity, trade-in, repair, recycling and impact pages
- Responsive desktop/tablet/mobile design

Open `index.html` in a browser or serve the folder with a local static server.

Note: Product photography uses remote Unsplash image URLs for the demo. Replace these with your licensed production assets before launch.
